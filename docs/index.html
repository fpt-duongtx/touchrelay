TouchRelay for Mac

Make an external USB touchscreen work natively on macOS: tap, drag, smooth scrolling with momentum, pinch-to-zoom and multi-finger swipes. Giúp màn hình cảm ứng USB rời hoạt động như native trên macOS: chạm, kéo, cuộn mượt có quán tính, pinch-zoom và vuốt nhiều ngón.

Why it existsVì sao cần

macOS has no support for third-party touchscreens: plug one in and it acts like a one-point mouse. No scrolling, no pinch, and two fingers make a mess. TouchRelay reads the screen's raw HID reports, recognises gestures and sends the events macOS apps already understand. macOS không hỗ trợ màn hình cảm ứng của bên thứ ba: cắm vào chỉ như một con chuột 1 điểm, không cuộn, không pinch, chạm 2 ngón thì loạn. TouchRelay đọc báo cáo HID thô của màn hình, nhận diện cử chỉ và gửi các sự kiện mà app macOS đã hiểu.

InstallCài đặt

macOS 13 or later, Apple Silicon or Intel.macOS 13 trở lên, Apple Silicon hoặc Intel.

Option A: build from source (recommended)Cách A: tự build từ mã nguồn (khuyên dùng)

# Rust (rustup.rs) + Xcode Command Line Tools
git clone https://github.com/fpt-duongtx/touchrelay.git
cd touchrelay
INSTALL=1 ./scripts/make-app.sh
open /Applications/TouchRelay.app

Option B: download a prebuilt app (for the lazy)Cách B: tải bản build sẵn (cho ai lười)

Download TouchRelay.zip (a universal Apple Silicon + Intel app) with its MD5 and SHA-256 checksums from Releases. Copy these lines into Terminal: they download the latest version, check the MD5, install it and mark it as trusted (removes the quarantine flag), then open it. Tải TouchRelay.zip (app universal Apple Silicon + Intel) cùng mã MD5 và SHA-256 ở trang Releases. Dán các dòng sau vào Terminal: tải bản mới nhất, kiểm tra MD5, cài vào Applications và đánh dấu tin cậy (gỡ cờ quarantine), rồi mở app. 

cd ~/Downloads
curl -fLO https://github.com/fpt-duongtx/touchrelay/releases/latest/download/TouchRelay.zip
curl -fLO https://github.com/fpt-duongtx/touchrelay/releases/latest/download/TouchRelay.zip.md5
[ "$(md5 -q TouchRelay.zip)" = "$(cut -d' ' -f1 TouchRelay.zip.md5)" ] && echo "MD5 OK" || echo "MD5 MISMATCH - stop here"
unzip -oq TouchRelay.zip -d /Applications
xattr -dr com.apple.quarantine /Applications/TouchRelay.app
open /Applications/TouchRelay.app
Not notarized. The maintainer does not have a paid Apple Developer ID, so the app is ad-hoc signed and macOS would warn if you opened a browser download directly. The commands above avoid that warning, but they also skip Apple's check, so only run them if you trust this repository and the MD5 says OK. A new version may ask you to grant the permissions again. If you prefer, use Option A and build it yourself. Chưa notarize. Người duy trì không có Apple Developer ID trả phí, nên app chỉ ký ad-hoc và macOS sẽ cảnh báo nếu bạn mở trực tiếp bản tải từ trình duyệt. Các lệnh trên tránh cảnh báo đó nhưng cũng bỏ qua bước kiểm tra của Apple, nên chỉ chạy khi bạn tin repository này và MD5 báo OK. Phiên bản mới có thể yêu cầu cấp lại quyền. Nếu muốn chắc chắn, hãy dùng cách A để tự build.

FAQ

Is it on the Mac App Store?Có trên Mac App Store không?

No. The sandbox blocks posting events, the Accessibility API and exclusive HID access, which this app needs.Không. Sandbox chặn phát sự kiện, Accessibility API và chiếm độc quyền HID, những thứ app cần.

Does it collect data?Có thu thập dữ liệu không?

No. It has no network code, analytics or auto-update.Không. App không có mã mạng, phân tích hay tự cập nhật.

Why can't I tap the very edge?Vì sao không chạm được sát mép?

Some sensors do not cover the whole panel. The Touch area test shows where; TouchRelay can stretch the reachable area to the edge.Một số cảm biến không phủ hết tấm nền. Kiểm tra vùng chạm cho thấy chỗ nào; TouchRelay có thể kéo vùng chạm được ra tới mép.
